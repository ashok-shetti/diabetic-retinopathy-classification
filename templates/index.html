CNN · TensorFlow/Keras · APTOS 2019 · Flask

The Problem

Diabetic retinopathy is a leading cause of blindness worldwide. Regular screening is critical, yet manual ophthalmological evaluations are resource-intensive, slow, and often inaccessible in underserved healthcare sectors.

The Solution

This project uses an Xception CNN trained on retinal fundus images to classify diabetic retinopathy into five severity levels through a Flask web application.

For educational and demonstration purposes only. This application is not a substitute for professional medical diagnosis.
